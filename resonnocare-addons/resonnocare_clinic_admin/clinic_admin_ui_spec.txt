# CLINIC ADMIN — UI & ACTIONS (CLIENT-ALIGNED, PROD-READY)

## 1️⃣ WHO THIS UI IS FOR (RECONFIRM)

**Clinic Admin = Operational owner of ONE Resonnocare Clinic (RC / Store)**

From client requirements, this role exists to:

- Run **daily clinic operations**
    
- Coordinate staff, appointments, inventory
    
- Monitor performance
    
- Act as interface with HQ
    

They **do NOT**:

- Configure platform
    
- Change master data
    
- Handle payments (B2B)
    
- See other clinics
    

This UI must feel like:

> “I run _my_ clinic, nothing else.”

---

## 2️⃣ LOGIN & CONTEXT SETUP

### Login Screen

- Email / Password
    
- First login → force password reset
    

### Context (AUTO, NO UI)

- Clinic locked (RC XYZ)
    
- Timezone = clinic timezone
    
- Language (if needed)
    

🚫 No clinic switcher  
🚫 No company dropdown

---

## 3️⃣ LANDING SCREEN — CLINIC DASHBOARD

### Screen: **Clinic Admin Dashboard**

This is the **home screen**.

### Purpose

> “How is my clinic doing **today**?”

---

### DASHBOARD WIDGETS (STRICTLY FROM CLIENT OPS VIEW)

#### Operations (Top Priority)

- Today’s Appointments
    
- Walk-ins Today
    
- Registrations Today
    
- Patients Waiting
    
- Pending Consultations
    

#### Clinical

- Doctors On Duty
    
- Pending Reports
    
- Follow-ups Due Today
    

#### Inventory

- Devices Available
    
- Devices Assigned
    
- Low Stock Alerts
    

#### Alerts

- Missed Appointments
    
- System Issues (if any)
    

🚫 No revenue totals  
🚫 No cross-clinic data  
🚫 No CRM lead funnel

---

## 4️⃣ MAIN NAVIGATION (LEFT SIDEBAR)

Clinic Admin should see **only what they can act on**.

### Menus Visible

1. **Dashboard**
    
2. **Staff**
    
3. **Appointments**
    
4. **Patients**
    
5. **Inventory**
    
6. **Billing (Reference)**
    
7. **Reports**
    
8. **Support / Escalations**
    
9. **Clinic Profile (Read-Only)**
    

That’s it.  
No CRM config, no HR policies, no integrations.

---

## 5️⃣ STAFF MENU (LOCAL CONTROL)

### Screen: Staff List (Clinic-Scoped)

**List Columns**

- Name
    
- Role (Doctor / Front Desk / Technician)
    
- Status (Active / Inactive)
    
- Shift
    

---

### Actions Allowed

#### ➕ Create Staff User

- Front Desk
    
- Doctor / Audiologist
    
- Technician
    
- Call Centre (if clinic-specific)
    

**Form Fields**

- Name
    
- Phone
    
- Email
    
- Role
    
- Shift timing
    
- Doctor availability (if doctor)
    

➡️ User auto-assigned to this clinic  
➡️ No role creation here (only assignment)

---

#### ✏️ Edit Staff

- Change shift
    
- Activate / deactivate
    

🚫 Cannot change role definitions  
🚫 Cannot see staff of other clinics

---

## 6️⃣ APPOINTMENTS MENU
