## 🟢 STAGE 0 — OUTSIDE SYSTEM (PRE-LEAD)

### Actors

* Marketing
* Call Centre
* Walk-in enquiry
* Doctor referral

### System State

❌ No Lead
❌ No Patient
❌ No OTP
❌ No Clinic ownership

📌 **No role in system involved**

---

## 🟢 STAGE 1 — LEAD CREATION (CRM ENTRY)

### Screen

**CRM → Leads → Create**

### Role Allowed

* ✅ CRM / Call Centre
* ⚠️ Front Desk (Enquiry only, no registration)

### Model

`crm.lead`

### Mandatory Fields

* Phone Number (required)
* Lead Source (UTM / Manual)
* Interested Clinic (preference)

### Rules (ENFORCED)

* Phone NOT unique
* Name optional
* No OTP
* No patient creation
* No clinic lock

📌 Output: **Lead ID created**

---

## 🟢 STAGE 2 — LEAD ALLOCATION (AUTO)

### Role

* System (no human)

### Mechanism

* Round Robin via `crm.team`
* Or assignment rules

### UI

❌ No screen
❌ No manual override by agent

📌 Agent becomes **Lead Owner**

---

## 🟢 STAGE 3 — CALL HANDLING & DISPOSITION

(**CORE CRM ENGINE**)

### Screen

**CRM → Lead → Call Disposition Panel**

![Image](https://www.images.cybrosys.com/blog/Uploads/BlogImage/how-to-add-chatter-to-form-view-in-odoo-17-1.png)

![Image](https://www.images.cybrosys.com/images/odoo-book/v17-ce/community/crm/odoo-book-v17-ce-crm-035.gif)

### Role

* ✅ CRM / Call Centre ONLY

### Required Action

Every call attempt MUST end with:

* Disposition selection
* Remarks
* Save

---

### 📌 Disposition Master (LOCKED)

Mapped **1:1** from Excel
Stored in `crm.disposition`

Fields:

* Disposition Name
* Follow-up Days
* Max Attempts
* Lead Relevancy

❌ CRM agents cannot edit this

---

### System Actions (AUTOMATIC)

On disposition save:

* Call log created (`mail.message`)
* Attempt count incremented
* Follow-up date computed
* Activity auto-created (if allowed)

### Enforcement

* Max attempts reached → Lead auto-churned
* Non-relevant → No follow-ups

📌 CRM is **persistence-driven**

---

## 🟢 STAGE 4 — FOLLOW-UP CYCLE

### Screen

**CRM → Activities**

### Role

* ✅ CRM / Call Centre

### Workflow

* Agent works from Due list
* Every follow-up = new call
* Every call = new disposition

📌 Fully native Odoo behavior

(**HARD HANDOFF**)

### Screen
