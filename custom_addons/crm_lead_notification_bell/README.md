# CRM Lead Notification Bell for Odoo 18

## Overview
This module adds a notification bell icon in the top right corner that shows notifications when CRM leads change stages.

## Features
- Real-time notifications when lead stages change
- Visual bell icon with unread count badge
- Clickable notifications that open the related lead
- Mark notifications as read/unread
- Email notifications for stage changes (optional)
- Browser notifications support
- User-specific notifications

## Installation
1. Copy the module to your Odoo addons directory
2. Update the module list
3. Install "CRM Lead Notification Bell" module

## Usage
- The bell icon appears in the top right corner after installation
- Red badge shows number of unread notifications
- Click the bell to see all notifications
- Click any notification to open the related lead
- Stage changes automatically create notifications

## Configuration
User notification settings can be configured in:
Settings > Users & Companies > Users > [Select User] > Notification Settings
